# task-tracker

TaskFlow — трекер задач на React + TypeScript.

## Что умеет проект
- Отображает доску с тремя колонками: To Do, In Progress, Done.
- Показывает полосу прогресса и количество задач в колонках.
- У задач есть приоритет, срок и счетчик подзадач.
- Данные сохраняются в localStorage (не пропадают после перезагрузки).

## Как запустить
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm run dev`

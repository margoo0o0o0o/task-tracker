# task-tracker

TaskFlow — трекер задач, разработанный на React + TypeScript с использованием Vite.

## Что умеет проект (на текущем этапе)
- Отображает список задач с их статусами, приоритетами и сроками.
- Типы данных описаны в `src/types.ts`.
- Тестовые данные находятся в `src/data/mockTasks.ts`.
